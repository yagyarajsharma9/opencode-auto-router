# Changelog

## [1.0.0] - 2026-07-28

### Added
- Initial release of opencode-auto-router
- Silent auto LLM routing with fallback chain support
- Automatic detection of rate limit, quota exceeded, overloaded, and model unavailable errors
- Per-session fallback tracking with cooldown support
- Model usage tracking and reporting
- Configurable error detection rules
- Support for 75+ OpenCode providers through Models.dev
- TypeScript support with full type safety
- Plugin hooks integration with OpenCode v2 plugin system
